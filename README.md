# Топ топ айти

Учебный прототип сюжетной университетской RPG на Java и Swing. На стартовом экране — пиксельное название и голубоватая кнопка «Играть». Кнопка открывает университетский двор по изображению пользователя.

## Запуск

**На компьютере автора:** откройте папку проекта и дважды нажмите `run.bat`, затем кнопку «Играть». Всё необходимое уже есть: скрипт использует JDK из PyCharm.

**На другом ноутбуке с Windows:**

1. Установите JDK 17 или новее (именно JDK, а не только JRE). Добавьте папку `bin` установленного JDK в `PATH`, если установщик не сделал это автоматически.
2. Скачайте репозиторий целиком через **Code → Download ZIP** и распакуйте, либо клонируйте через Git. Папки `src` и `assets` должны остаться рядом с `run.bat`.
3. Дважды нажмите `run.bat`, дождитесь окна и нажмите «Играть».

Редактор кода, PyCharm и Git при скачивании ZIP не обязательны. Скрипт сам компилирует исходники. Если окно закрывается с ошибкой, проверьте в новом терминале `java -version` и `javac -version`: обе команды должны указывать Java 17 или новее.

Эти скрипты рассчитаны на Windows. Для macOS/Linux из папки проекта с установленным JDK: `javac -encoding UTF-8 -d build src/*.java`, затем `java -cp build Main`.

## Управление

- WASD или стрелки — движение чёрного квадрата. Для WASD используйте английскую раскладку.
- R — вернуться на старт во дворе.

## Первый диалог

Голубой квадрат справа от стартовой позиции — NPC. Подойдите к нему: в радиусе 100 пикселей появятся «Привет!» и кнопка «Диалог». Нажмите кнопку — снизу откроется окно с маленьким квадратным портретом слева и единственной репликой «Привет!». Во время разговора движение остановлено. Кнопка «Далее» закрывает окно и возвращает движение.

`Npc.java` отвечает за положение, вид и радиус взаимодействия. `DialoguePanel.java` — за окно и кнопку завершения. `GamePanel.java` переключает обычный режим и диалог. Ветвлений, озвучки и дополнительных реплик пока нет.

## Карта и камера

Фон находится в `assets/maps/university-courtyard.png`, его размер — 1536×1024. Окно показывает область 800×556 без растягивания изображения. Камера следует за игроком и останавливается у краёв карты.

`World.java` один раз загружает PNG и проверяет границы и препятствия. Препятствия пока заданы приблизительными прямоугольниками для здания, деревьев и самолёта. Картинка сама по себе не определяет столкновения. Кроны не перекрывают игрока отдельным передним слоем.

`Player.java` хранит координаты и рисует чёрный квадрат 16×16. `Camera.java` вычисляет сдвиг видимой области. `GamePanel.java` получает клавиши, обновляет движение и рисует фон и игрока через одну камеру. `Main.java` создаёт окно и переключает меню на локацию.

`MenuPanel.java` собирает меню, `PixelButton.java` рисует состояния кнопки, `PixelFont.java` рисует нужные буквы сеткой 5×7. Это пока небольшой набор символов для меню, а не полный алфавит.

Для замены фона на изображение с другой геометрией нужно также изменить препятствия и точку появления в `World.java`. Переход во вторую локацию пока не реализован.

Папки `.tools` и `build` игнорируются Git. Будущие идеи записаны в `future-ideas/IDEAS.md`; источники стандартных подходов — в `docs/LIBGDX_REFERENCE.md`.
