# Топ топ айти

Учебный прототип сюжетной университетской RPG на Java и [LibGDX](https://libgdx.com/). На стартовом экране пиксельное название и кнопка «Играть». Кнопка открывает университетский двор, по которому ходит персонаж, рядом стоит NPC, с которым можно поговорить.

## Запуск

Нужен JDK 17 или новее (именно JDK, а не только JRE).

**Windows:** дважды нажмите `run.bat`, затем кнопку «Играть». Первый запуск идёт дольше: Gradle скачивает себя и LibGDX, нужен интернет.

**Из терминала** в папке проекта:

```
gradlew lwjgl3:run
```

На macOS/Linux: `./gradlew lwjgl3:run`.

**Из IntelliJ IDEA:** откройте папку проекта, IDEA сама распознает Gradle-проект. Запуск через панель Gradle: `lwjgl3 → Tasks → application → run`. Если запускать класс `Lwjgl3Launcher` напрямую, в настройках запуска укажите Working directory = папка `assets`, иначе игра не найдёт карту.

## Управление

- WASD или стрелки — движение. Раскладка клавиатуры не важна.
- R — вернуться на старт.
- Подойдите к голубому квадрату, появится «Привет!» и кнопка «Диалог». Во время разговора движение остановлено, кнопка «Далее» закрывает окно.

## Структура

```
assets/        картинки игры (карта двора)
core/          сама игра
lwjgl3/        запуск игры на компьютере (окно, настройки)
```

Классы в `core/src/main/java/topit`:

- `TopItGame` — главный класс, переключает экраны меню и игры.
- `MenuScreen` — стартовый экран с названием и кнопкой.
- `GameScreen` — игровой экран: ввод, обновление, камера, интерфейс.
- `World` — карта и препятствия, проверка, можно ли встать в точку.
- `Player` — положение и движение игрока.
- `Npc` — положение NPC и проверка, рядом ли игрок.
- `WorldRenderer` — рисует карту, NPC и игрока.
- `DialogueBox` — окно диалога с кнопкой «Далее».
- `PixelButton` — пиксельная кнопка.
- `PixelFont` — пиксельный шрифт, буквы заданы сеткой 5×7. Пока только нужные буквы, а не весь алфавит.
- `Painter` — общий `SpriteBatch` и метод рисования прямоугольников.

Логика (`World`, `Player`, `Npc`) отделена от отрисовки (`WorldRenderer`). В LibGDX ось y направлена вверх, поэтому координаты препятствий и NPC отсчитываются от нижнего края карты.

## Карта

Фон: `assets/maps/university-courtyard.png`, 1536×1024. Окно показывает область 800×556, камера следует за игроком и останавливается у краёв карты. Препятствия заданы приблизительными прямоугольниками в `World.java`, сама картинка столкновения не определяет. Если заменить фон, нужно поменять и препятствия, и точку появления.
